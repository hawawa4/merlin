# Which plugins are which instrument. The scanner reads this to tag plugins automatically
# (unless the user tagged that plugin by hand).
#
# One rule per line:   Family > Instrument ; Family > Another : pattern, pattern, vendor:pattern
#   - Tags are named as in the taxonomy (app/src/tags.rs). `Family` alone tags only the family.
#   - A pattern matches the plugin's name (or, with `vendor:`, its vendor or the categories it
#     lists, where some plugins put their maker) from the start of any
#     word, ignoring case and punctuation: `piano` matches "Pianoteq" and "Grand Piano", `b-3`
#     matches "B-3 V". A trailing `$` also requires the word to end there: `organ$` matches
#     "Organ" but not "Organic". Several words must follow each other.
#   - The FIRST rule that matches wins, so put specific things above general words
#     ("electric piano" above "piano").
#   - Anything no rule matches falls back on the plugin's own category (CLAP/VST3 features).
# Add lines freely; `cargo test` checks that every tag exists.
