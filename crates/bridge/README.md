# merlin-bridge

Loads Windows plugins in any Linux plugin host (REAPER, Bitwig, Ardour, ...), with the Wine and
yabridge the app ships. `merlin-bridge --help` lists the commands; `just bridge --help`
runs it from the repository. How it works, and how it relates to the app's own bridges, is in
[docs/wine.md](../../docs/wine.md).
